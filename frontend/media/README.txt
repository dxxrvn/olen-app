Сюда нужно положить медиа-файлы из оригинального репозитория
(https://github.com/dxxrvn/app, папка public/media).

Быстрый способ (из корня проекта):

    cd frontend/media
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/hero.mp4
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/lofi.mp4
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/logo.png
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/logophoto.png
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/logotext.png
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/music.mp3
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/nature.mp3
    curl -O https://raw.githubusercontent.com/dxxrvn/app/main/public/media/rain.mp3

Приложение работает и без них: вместо видео покажется градиент,
а кнопки звуков станут неактивными.
